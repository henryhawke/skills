# Validation Profiles

## Theme or shared component

Run `dart format` on changed files, targeted `flutter analyze`, direct widget/unit tests, then all theme/component tests if shared tokens changed.

## Incoming reaction

Cover consent granted/denied, hold start, cancel, release, playback error, app background, preview, re-record, discard, send failure, and reduced motion. Device camera/mic behavior requires physical-device evidence.

## Fart Map filter

Cover All, Friends with matches, Friends empty, friend data loading/error, cached/offline drops, selection reset/preservation, and proof that private sends are excluded. Backend/RLS guarantees require integration or migration evidence, not widget tests alone.

## Visual review

Check one hero, semantic accent usage, fixed radii/spacing, no nested-card clutter, one icon family, contrast, large text, and all six control microstates.
