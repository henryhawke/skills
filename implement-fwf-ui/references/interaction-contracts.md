# FWF Interaction Contracts

## Global fart action

- Show `assets/images/icon.png` inside the 80px control.
- Tap quick-sends; hold records up to the configured limit.
- Preserve pressure, recording, cooldown, error, haptic, and semantic states.

## Listen and reaction

- Press-and-hold controls both playback and consented reaction capture.
- Start capture with the hold; stop/cancel capture whenever playback stops, hold cancels, route backgrounds, or an error occurs.
- Never start a camera before consent and platform permission.
- Show an explicit recording indicator and camera preview during the hold.
- Always present preview with re-record, discard, effects, listen again, and send; never auto-send.

## Fart Map filter

- `All` shows all visible public drops.
- `Friends` shows only public drops whose author is in the current user's accepted-friend set.
- Private sends never enter either data set.
- Preserve selected marker, cluster, cached/offline status, and empty-state behavior when switching filters.
